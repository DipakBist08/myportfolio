import os

import pytest
from playwright.sync_api import Page, expect


@pytest.fixture(autouse=True)
def setup(page: Page):
    page.goto("https://app.example.com")


def test_login(page: Page):
    page.get_by_label("Email").fill(os.environ["USER_EMAIL"])
    page.get_by_label("Password").fill(os.environ["USER_PASSWORD"])
    page.get_by_role("button", name="Sign in").click()
    expect(page).to_have_title("Dashboard")

My Quality Engineering Workflow

0/10 steps

Ten steps, in the order they happen on a real ticket. Each one ticks as you reach it.

  1. 01 Plan

    Requirements

    I read the requirement before the ticket, and write down what is ambiguous.

  2. 02

    Risk analysis

    Which failures would cost the most? That ranking decides where the effort goes.

  3. 03

    Test planning

    Scenarios and cases mapped back to requirements, so coverage is arguable.

  4. 04 Test

    Manual testing

    Exploratory passes first — scripted cases only find what they were written for.

  5. 05

    API validation

    Contract, auth and error paths checked at the service layer before the UI.

  6. 06

    Automation

    Regression-critical journeys move into Playwright so they run every time.

  7. 07

    Performance

    JMeter against the paths that carry load, watching where latency turns.

  8. 08 Release

    Regression

    The automated suite runs on every change; failures are triaged, not muted.

  9. 09

    Release validation

    UAT and a smoke pass against the release build before sign-off.

  10. 10 Learn

    Continuous improvement

    Every escaped defect becomes a new case and a question about why.

Then back to 01, Requirements: the loop starts again.

How I Use AI in Quality Engineering

I integrate AI into my Quality Engineering workflow to improve efficiency, accelerate test development and streamline repetitive QA activities. I use Claude Code as an engineering assistant across test design, automation development, debugging and QA documentation.

My approach is built around human oversight and engineering judgement. AI helps accelerate implementation, explore scenarios and reduce repetitive work, while I remain responsible for test strategy, risk assessment, technical decisions and quality validation.

Every AI-generated output is critically reviewed, validated against business requirements and refined before being introduced into the automation framework or project workflow. AI supports my engineering process; it does not replace the reasoning behind it.
